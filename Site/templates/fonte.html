Como preparar o caminho Databricks

1. No Databricks

  • Notebook 02 publicado: tabela {{ databricks.tabela }}.
  • Notebook 08 com EMPACOTAR_CAMPEAO = True: grava o .pkl em {{ databricks.modelo }}.
  • Figuras do notebook 03 salvas em {{ databricks.graficos }}, com os mesmos nomes de restrito/graficos/.
  • Um SQL warehouse ligado e um token com leitura na tabela e no Volume.

2. Mesma versão do scikit-learn

O .pkl só abre com a versão que o gerou. Se o Databricks usar outra, o teste avisa; ajuste o requirements.txt do site para a versão do Databricks.

3. Credenciais no servidor do site

Em variáveis de ambiente (precedência) ou em instance/databricks.json (fora do controle de versão — use o modelo databricks.exemplo.json):

DATABRICKS_HOST=https://<workspace>.cloud.databricks.com
DATABRICKS_TOKEN=dapi...
DATABRICKS_WAREHOUSE_ID=<id do warehouse>
DATABRICKS_TABELA={{ databricks.tabela }}   (opcional)
DATABRICKS_VOLUME=/Volumes/...               (opcional)

O token nunca é digitado nesta página nem aparece em log. Configurado em: {{ databricks.origem_config }}.
